## Tentang Saya

Saya pengembang dari Indonesia yang fokus pada **Node.js** dan **JavaScript modern (ESM)**.

Saya suka membuat software yang sederhana, mudah dipahami, modular, dan berguna. Terutama untuk otomatisasi, bot, sistem pesan, dan alat bantu pengembang.

## Yang Saya Kerjakan

**Node.js**  
Membuat backend, bot, alat otomatisasi, CLI, dan aplikasi berbasis event.

**JavaScript**  
Menggunakan JavaScript modern dengan ESM, proses async, dan struktur kode yang modular.

**Open Source**  
Membuat proyek yang mudah dipelajari, dikembangkan, dan digunakan kembali.
